# Искра: интерфейс

Искра — локальный рабочий стол для проверки идеи и подготовки контакта с потенциальным клиентом. Основной путь: идея → поиск → проверка публикаций → лид → черновик.

## Визуальная система

- Тихая светлая основа `#f7f8f6`, белые рабочие панели, зелёный акцент `#0d9173`, тёмный текст `#1d2927`.
- Основной шрифт — системный sans serif. Числа, метки и заголовки отделяются размером и насыщенностью.
- Карточки с мягкой рамкой и скруглением; цвет используется для действий и состояний, а не для декоративной заливки всего экрана.
- На узком экране панели становятся одной колонкой. Навигация остаётся доступной сверху.

## Контентная студия

Слева редактируются факты о курсе, справа объясняется назначение вариантов. Ниже идут шесть коротких постов и сохранённые черновики. Главный визуальный акцент — зелёная кнопка генерации. Даты и стоимость входят в пост только после подтверждения пользователем. Текст варианта редактируется до сохранения.

## Поведение

- Данные хранятся локально в браузере. Черновики не публикуются автоматически.
- Успех подтверждается кратким сообщением. Ошибки заполнения показываются рядом с действием.
- `select` остаётся нативным: его всплывающее меню принадлежит браузеру/операционной системе.
- Поля текста используют фиксированную геометрию с внутренней прокруткой, чтобы длинный текст не менял сетку карточек.
- Все интерактивные элементы должны иметь видимое состояние фокуса.
