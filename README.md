# Искра

Локальное приложение для проверки бизнес-идеи через публичные обсуждения в Threads: фразы поиска → найденные публикации → список потенциальных лидов → черновики ответов и постов.

## Запуск

Нужны Node.js 20+ и установленный Google Chrome. Из папки проекта:

```bash
npm install
npm run dev
```

Открой [http://127.0.0.1:5173](http://127.0.0.1:5173). Нажми **«Проверка спроса» → «Открыть браузер»**, войди в Threads в открывшемся окне, затем нажми **«Найти публикации»**. Приложение проверит до восьми активных фраз за один запуск и покажет видимые результаты. Если Chrome отсутствует, можно установить браузер Playwright командой `npx playwright install chromium`.

Чтобы повторять поиск, в разделе **«Следить за новыми постами»** выбери интервал и включи наблюдение. На компьютере должны оставаться запущенными `npm run dev` и браузерная сессия; спящий или выключенный компьютер не выполнит проверку. Найденные посты сохраняются локально и появляются в разделе проверки спроса. Можно включить наблюдение только для одной идеи одновременно.

Для сборки интерфейса: `npm run build`. Для локальной работы нужны оба процесса из `npm run dev`: Vite и локальный сервер на `127.0.0.1:4318`.

## Что уже работает

- Несколько идей с отдельными фразами, находками, лидами и черновиками.
- Редактирование и включение поисковых фраз; быстрые ссылки на свежую выдачу Threads.
- Локальный браузер с отдельным профилем для входа в Threads и последовательного поиска.
- Извлечение видимых публикаций со страницы поиска, удаление дублей, первичная пометка запросов по словам намерения.
- Периодическая проверка каждые 30 минут, 1, 3 или 6 часов с локальным сохранением результатов.
- Ручное сохранение доказательств спроса, перевод в лиды, статусы и заметки.
- Черновики поста и ответа из описания идеи, которые можно редактировать и копировать.
- Генератор шести коротких постов Threads из фактов о курсе. Пример Narxoz AI Juniors заполнен по предоставленному материалу; даты и цена попадают в текст только после отдельного подтверждения.
- Фильтр находок проверяет текст самой публикации: тема и аудитория задаются словами через запятую; по умолчанию видны только посты за последние 7 дней. Можно выбрать 24 часа или 30 дней. Публикации без даты и вне периода не показываются даже среди отсеянных. Тематические обсуждения можно открыть отдельно. Свежие посты не по теме вынесены в режим проверки фильтра, где они помечены как неподходящие и не сохраняются как лиды. Число найденных Threads постов не считается числом лидов.
- Экспорт данных в JSON.

## Где хранятся данные

Идеи, сохранённые доказательства, лиды и черновики хранятся в `localStorage` текущего браузера. Автоматически найденные публикации и расписание лежат в `.local/`; сессия Threads — в `.local/threads-browser/`. Папка исключена из Git. Приложение не получает пароль Threads и не отправляет сообщения или посты автоматически.

## Ограничения текущей версии

Сбор публикаций использует видимую страницу Threads, а не официальный API. Meta может изменить разметку, порядок выдачи или потребовать повторный вход. Поиск не гарантирует полноту всех публикаций. Если автоматическое извлечение не сработало, можно открыть запрос вручную и добавить ссылку на конкретный пост через **«Добавить пост»**.

Подсчёт «сигналов спроса» показывает количество сохранённых явных запросов. Это материал для качественной проверки идеи, а не статистическая оценка рынка. Генератор использует локальные структуры, а не AI API; тексты требуют редактирования и проверки человеком. Охват и обращения не гарантируются.
