# Решения перед следующей автоматизацией

Текущая версия работает локально и открывает Threads в отдельном браузере. Эти решения нужны для следующих этапов; они не блокируют запуск приложения.

1. **Источник данных для публичного сервиса.** Локальный браузер уже может периодически искать видимые посты, пока открыт компьютер и приложение. Для устойчивого сервиса с несколькими пользователями потребуется официальное разрешение `threads_keyword_search` от Meta или другой согласованный источник данных.
2. **AI для фраз и текстов.** Нужно выбрать поставщика модели, способ оплаты и порядок обработки отправляемого текста. До подключения внешнего API работают локальные шаблоны и ручное редактирование.
3. **Публикация и ответы.** Сейчас приложение готовит черновики. Автоматическая отправка в Threads потребует отдельного разрешения и ясного правила: одобрять каждый ответ или разрешить ограниченную автоматическую публикацию.
4. **Почта и уведомления.** Для Gmail или другого почтового сервиса нужно решить, получать ли только уведомления о новых находках или также отправлять письма. Отправка писем другим людям требует отдельного явного разрешения.
5. **Публичный запуск.** Сейчас данные находятся в браузере одного пользователя. Перед публикацией сервиса понадобятся аккаунты, серверное хранение, политика конфиденциальности и защита подключённых токенов.

Пока эти решения не приняты, приложение можно использовать для проверки одной или нескольких идей на собственном компьютере.
